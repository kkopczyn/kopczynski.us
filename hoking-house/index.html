Hoking House Home Assistant

A private home automation system for one household. Not a public service; there is nothing to sign up for.

What it is

Hoking House runs a private Home Assistant server for the Kopczynski family. It connects to the family's own Google Calendar so a kitchen display can show the family's schedule and update shared events (for example, who is doing school drop-off).

Only members of the household use it. Access is limited to accounts the developer has approved.

Privacy policy

  • What it accesses: the calendars on the signed-in Google account, to read events and to create or remove events the household asks it to.
  • Where data goes: calendar data is stored and processed on the household's own Home Assistant server. It is not sold, shared, or used for advertising.
  • Who can see it: only members of the household.
  • Retention: data stays only as long as the integration is connected. Disconnecting it in Home Assistant, or removing access at myaccount.google.com/permissions, stops all access.
  • Google user data: use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Terms

This is a personal, non-commercial system provided as-is for the household's own use. There is no service offered to the public.
